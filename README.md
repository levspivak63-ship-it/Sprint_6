Автотесты для учебного сервиса "Яндекс.Самокат".

Проект включает автоматизацию тестовых сценариев с использованием Selenium и Page Object Pattern.

В проекте испоьзованы технологии: selenium==4.37.0 allure-pytest==2.15.0 pytest==8.4.2 webdriver-manager==4.0.2 requests==2.32.5 urllib3==2.5.0

Структура проекта: Sprint_6/ ├── pages/ # Page Object классы │ ├── base_page.py # Базовый класс страницы │ ├── main_page.py # Главная страница │ └── order_page.py # Страница заказа ├── tests/ # Тестовые классы │ ├── test_questions.py # Тесты выпадающего списка │ ├── test_order.py # Тесты заказа самоката │ └── test_logos.py # Тесты логотипов ├── allure-report/ # Allure отчет (статический) ├── conftest.py # Фикстуры pytest ├── requirements.txt # Зависимости проекта └── README.md # Документация

Тесты проводились в браузере FireFox версии 144.0 в полноэкранном режиме с разрешением 2560 х 1440

Тестовые сценарии:

Проверка логотипов 2 теста:

Логотип Самоката → переход на главную страницу
Логотип Яндекса → открытие Дзена в новом окне
Выпадающий список "Вопросы о важном" 8 параметризированных тестов:

При нажатии на каждый вопрос открывается соответствующий текст ответа
Заказ самоката 2 параметризированных теста:

Полный позитивный сценарий заказа по верхней кнопке "Заказать"
Полный позитивный сценарий заказа по нижней кнопке "Заказать"
Результаты тестирования: всего 12 тестов успешных 12 (100%) проваленных 0
